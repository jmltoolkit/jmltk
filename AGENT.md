# AGENT.md

**JML-toolkit fork of JavaParser**, written in Java / Kotlin.

## Convention for Tests
- Assertions from AssertJ or Google Truth are available
- Use `var` modifier


## Javadoc / KDoc conventions
- On AST classes, also add examples of the underlying syntax construct.

## Grammar + Convention
- Grammar: `javaparser-core/src/main/javacc/java.jj`
- Generated parser: `javaparser-core/build/generated-src/main/javacc/com/github/javaparser/GeneratedJavaParser.java`
  (regenerated by the `compileJavacc`
- New tokens must be declared with a dedicated lexer rule. Do not reorder existing rules.
- **`TokenTypes.java`:** every token kind must be classified in
  `com.github.javaparser.TokenTypes#getCategory(int)` breaks `TokenTypesTest`.

## Code generation workflow (do NOT hand-edit generated files)

```
./gradlew :jmlparser-core-metamodel-generator:run   # rewrites metamodel/*MetaModel.java
./gradlew :jmlparser-core-generators:run            # rewrites visitors (Clone, Equals, Modifier, HashCode, Observer, …),
                                                    # ObservableProperty, JavaToken kinds
./gradlew spotlessApply                             # normalizes headers + formatting
./gradlew :jmlparser-core:compileJava               # verify
./scripts/run-generators.sh                         # Regeneration pipeline 
```

## Working with AST classes

### Add new AST class
1. Class must be in Node.class hierarchy
2. Add attributes, mark with `@OptionalProperty`
3. Implement interfaces `NodeWith*` that fits the use case
4. Implement minimal requirements with minimal method stubs: visitor methods, constructor, and an `@AllFieldsConstructor` 
5. Add class to `ALL_NODE_CLASS` list. 
6. Run `./scripts/run-generators.sh`

### Strategy for class removal: 
1. Remove class from `ALL_NODE_CLASS` list
2. Run `./scripts/run-generators.sh` 
3. Fix the compiler errors: mainly to wrong overloading (visitors lost the visit-method)
4. Remove the class follow along its usages until fixed 

### Strategy for attribute removal:
1. Remove attribute from AST class
2. Fix the AST: getter and setter should be replaced by minimal version (`return null` and `return this`)
3. Run `./scripts/run-generators.sh`
4. Remove getter and setter
