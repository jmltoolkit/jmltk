Usage: main stubby [<options>] [<files>]...

  Generate Java stubs from class files, JRE classes. Is able to create an
  effective JML specifications folder

Options:
  -o, --output=<path>  Output directory for generated stubs
  --merge=<text>       Methods/classes given in this set are merged. Normally,
                       the first one wins.
  --class=<text>       specifies a list of classes using fqn
  -h, --help           Show this message and exit
